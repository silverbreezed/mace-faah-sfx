## Mace Meme - "Faah" Sound Effect (SFX)

Add some humor to your combat! This mod triggers the iconic "Faah" meme sound effect during these specific events:
- **Mace Kills**: Triggers when you defeat any entity or player using a Mace.
- **Totem Pops**: Triggers when you successfully pop another living entity's Totem of Undying using a Mace.
- **Breach Swap**: Triggers when you pop a totem or kill a player using the "Breach Swap" technique (switching to a Mace with the Breach enchantment).

Make every Mace kill more satisfying and funny with the iconic "Faah" meme sound. Lightweight, client-side, and multiplayer friendly.
